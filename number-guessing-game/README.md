\# Number Guessing Game



A simple console-based Number Guessing Game developed in C.



This project was created as part of my C programming practice. The computer generates a random number, and the player has to guess it with the help of hints until the correct number is found.



\## Features

\- Random number generation

\- User input

\- Higher/Lower hints

\- Attempt counter



\## Concepts Used

\- Loops

\- Conditional Statements

\- Functions

\- rand() function



\## Language

\- C



This project helped me improve my understanding of basic C programming concepts.
