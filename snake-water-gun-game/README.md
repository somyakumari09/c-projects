\# Snake Water Gun Game



A simple console-based Snake Water Gun Game developed in C.

This project was created as part of my C programming practice. In this game, the player competes against the computer by choosing Snake, Water, or Gun. The winner is decided based on the game rules.



\## Features

\- Play against the computer

\- Random computer choice

\- User input

\- Winner declaration

\- Multiple rounds (if implemented)



\## Concepts Used

\- Conditional Statements

\- Loops

\- Functions

\- rand() function



\## Language

\- C



This project helped me improve my understanding of basic C programming concepts and game logic.
